# KanjiVG

Stroke-order data in `src/data/kvg-strokes.json` is derived from
[KanjiVG](https://kanjivg.tagaini.net/) © Ulrich Apel and contributors, licensed
under [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
(full text in `COPYING`).

Modifications: a subset of 150 characters was extracted (kana + N5 kanji); the
stroke paths themselves are unmodified. The derived data remains under CC BY-SA.

In-app attribution lives on the `/tentang/` page, so it ships inside every
distributed copy of the app — the store builds included — rather than only in
this repository.
